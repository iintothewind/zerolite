# ZeroLite 1.2.0

ZeroLite 1.2.0 ships the WASM plugin host. It is the same `zeroclaw` binary,
config file and command set as 1.1.0, on upstream **ZeroClaw v0.8.6**.

Release builds embed the web dashboard. Platforms: Windows x64, Linux x64,
Linux arm64. No macOS build.

## What changed since 1.1.0

### The context engine is back in the code

1.1.0's notes advertised the context engine, but the upstream v0.8.6 merge had
reverted it: `[runtime_profiles.<alias>.context]` was accepted by the config
loader and then ignored, so the documented knobs did nothing. 1.2.0 restores it.

```toml
[runtime_profiles.coder.context]
request_token_ceiling = 100_000      # optional window ceiling
trim_threshold_percent = 80     # default water-line
reserve_tokens = 16_384         # output headroom
keep_recent_turns = 5           # default, clamped 1–10
```

- Trimming keeps the newest whole turns and never splits one. Past the
  water-line it drops older turns down to one; if the newest turn still does
  not fit, the turn fails.
- `keep_recent_turns` is clamped to `1..=10`. `trim_threshold_percent` must be
  in `1..=100` and `reserve_tokens` must not exceed 50% of the resolved model
  window — both are hard config errors, never silent clamps.
- Sends keep the longest byte-stable prefix, so the provider's prompt cache
  survives a trim. Cache hits are `zeroclaw_tokens_cached_input_total`.

Reference: [Context management](../design/context-management.md).

### `zeroclaw plugin` is in these archives

1.1.0 shipped `--features embedded-web` only, so the upstream v0.8.6 plugin host
was compiled out. These archives add `plugins-wasm-cranelift`:

- The release archives are built with
  `--features embedded-web,plugins-wasm-cranelift` — the web dashboard is
  embedded and the WASM plugin host is compiled in. ARM32 is not covered by
  these three targets; it would need `plugins-wasm-pulley` instead.
- `zeroclaw plugin` exists — list, search, install, update, remove, info, bind,
  migrate. `plugin list --verify` reports each installed package's host-load
  verdict.
- Registry packages ship as `.wasm` and are JIT-compiled on load by Cranelift, so
  a package is not bound to one host wasmtime version or target architecture.
  Without the JIT backend the host deserializes `.cwasm`, which must be
  recompiled for every wasmtime upgrade and per target.
- Plugins stay disabled until the operator enables them.

The 13 packages built for this release (Discord, Matrix, Telegram, Bluesky,
Gitea, Mattermost, Mochat, Notion, Reddit, X, WeChat, WeCom, and the
`redact-text` tool) install by name. Upstream tested Discord end-to-end from
release-candidate archives on Linux, Windows and macOS. See the
[upstream v0.8.6 notes](https://github.com/zeroclaw-labs/zeroclaw/releases/tag/v0.8.6)
for the per-channel status, including the ten that have not yet run against
their live services.

### Cost

The plugin host is Cranelift plus Wasmtime: expect roughly **+23%** binary size,
the same delta upstream measured for v0.8.6. Upstream raised its own release size
cap from 64 MiB to 80 MiB for this.

## Everything from 1.1.0

1.2.0 contains all of 1.1.0: the upstream v0.8.6 integration, the fork's
context engine (restored, see above), plus the web chat, session search, and
`gateway.master_pair_code`.

### Breaking changes inherited from upstream v0.8.6

- Pairing codes default to 32 characters and reading or minting them needs the
  gateway admin token. Set `[gateway.pairing_code] length = 6, charset = "numeric"`
  for the old shape.
- Remote WSS needs `auth_token`; `[security.nevis]` is retired in favour of
  `[oidc.<alias>]`.
- `[browser] enabled = true` no longer implies the `browser` automation tool; set
  `browser.automation_enabled = true`.
- `file_download` refuses private-network hosts unless they are listed in
  `[file_download] allowed_private_hosts`.
- Full autonomy no longer overrides `always_ask`.
- The shell follows the platform default; set `runtime.shell = "sh"` or `"cmd"`
  to pin the previous choice.

### Plugins built for v0.8.5 need a rebuild

Channel components must be rebuilt against this release's experimental `wit/v0`.
Precompiled `.cwasm` artifacts must be recompiled for Wasmtime 48. Registry
channel packages installed before v0.8.6 do not load on it — remove each one,
then install the current version by name with `--channel-alias`.

## Install

| Platform | Asset |
|---|---|
| Windows x64 | `zerolite-1.2.0-x86_64-pc-windows-msvc.zip` |
| Linux x64 | `zerolite-1.2.0-x86_64-unknown-linux-gnu.tar.gz` |
| Linux arm64 | `zerolite-1.2.0-aarch64-unknown-linux-gnu.tar.gz` |

Each binary carries the web dashboard. Verify the plugin host is present:

```sh
zeroclaw plugin list
zeroclaw status | grep -i plugin
```
