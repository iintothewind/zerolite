# ZeroLite 1.3.6

The `zeroclaw` CLI on the same upstream base as 1.3.5, ZeroClaw **v0.9.0**
(`6c78ba59b`). This release lets the web chat answer an agent's questions
(`ask_user`, `poll`) and stops `reaction` from reporting success where
nothing happened. No config or session-store migration: a 1.3.5 config and
`sessions.db` are used as they are. Platforms: Windows x64, Linux x64, Linux
arm64. No macOS build.

## Before you upgrade

- **Upgrading from 1.3.3?** Run `zeroclaw config migrate` once (config
  schema version 4), as described in the 1.3.4 notes.
- **`ask_user` and `poll` still ask for tool approval first** under a
  supervised risk profile. List them in the profile's `auto_approve` to go
  straight to the question.

## Web chat questions

- **A question card above the composer.** When an agent calls `ask_user`
  or `poll` in the web chat, the chat shows the question with one button per
  choice, a free-text "other" answer, Skip, and a countdown. Before, both
  tools failed with `did not complete the structured choice` /
  `did not complete the single-select poll`.
- **`ask_user` gains `multi_select`.** With `multi_select: true` the card
  shows checkboxes and Submit; the tool returns the picks one per line.
  Free-form questions (no `choices`) are answered by typing.
- **Several questions queue.** An agent asks several questions with several
  `ask_user` calls; the card shows them one at a time (`1/3`).
- **`poll` is one viewer's answer.** In the web chat a poll is a question
  to the person at the chat, counting down the poll's `duration_minutes`.
- **An unanswered question fails with its cause, and the turn continues:**
  `the user dismissed the question without answering`,
  `no web chat viewer is attached to answer the question` (the page was
  closed or reloaded), or `no answer within N seconds`. A reloaded page does
  not show the question again.
- **Scoped (OIDC non-admin) chats** answer choice questions only: no
  free-text answer and no countdown. Free-form questions stay refused there.

## Reactions

- **`reaction` in the web chat now fails** with
  `Failed to add reaction: the web chat has no message reactions; nothing was changed`.
  Before, it reported `Reaction added` for a message that does not exist.
  The same applies to scoped web chats and the ZeroCode Code tab
  (`this chat has no message reactions`).

## Install

| Platform | Asset |
|---|---|
| Windows x64 | `zerolite-1.3.6-x86_64-pc-windows-msvc.zip` |
| Linux x64 | `zerolite-1.3.6-x86_64-unknown-linux-gnu.tar.gz` |
| Linux arm64 | `zerolite-1.3.6-aarch64-unknown-linux-gnu.tar.gz` |

Each binary carries the web dashboard and the WASM plugin host
(`zeroclaw plugin list`). Replace the binary and restart the service.
