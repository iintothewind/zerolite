# ZeroLite 1.1.0

ZeroLite 1.1.0 moves the fork onto upstream **ZeroClaw v0.8.6**. It is the same
`zeroclaw` binary, config file and command set as 1.0.0. Crate version is `1.1.0`.

Release builds embed the web dashboard. Platforms: Windows x64, Linux x64,
Linux arm64. No macOS build.

## Upstream v0.8.6

Full upstream notes: <https://github.com/zeroclaw-labs/zeroclaw/releases/tag/v0.8.6>

### Not in these binaries

The WASM plugin host is the upstream headline of v0.8.6, but these archives are
built with `--features embedded-web` only. `plugins-wasm` is not a default
feature, so `zeroclaw plugin` is absent here. Build from source with
`--features embedded-web,plugins-wasm-cranelift` if you need it.

## ZeroLite additions carried forward from 1.0.0

### Context engine

`zeroclaw-context` sets the send budget and keeps the prefix cacheable. Policy is
on the runtime profile:

```toml
[runtime_profiles.coder.context]
request_token_ceiling = 100_000      # optional window ceiling
trim_threshold_percent = 80     # default water-line
reserve_tokens = 16_384         # output headroom
keep_recent_turns = 5           # default, clamped 1–10
```

- Past the water-line, keep the newest whole turns, then drop older ones down to
  one. A turn is never split. If the newest turn still does not fit, the turn fails.
- A trim rewrites stored history and refreshes the meter. Size is a script-aware
  estimate, then re-anchored on provider `input_tokens`.
- Sends keep the longest byte-stable prefix. Cache hits are
  `zeroclaw_tokens_cached_input_total` and the composer's cache-hit percent. A
  child's context budget cannot exceed its parent's.

### Web chat

- Context ring, plus `N turns · M steps · … tok · cache hit …%`.
- A turn is ordered steps. Earlier steps collapse; the answer stays open.
  The transcript stays pinned, and a trim cuts it in place.
- An `https://` markdown image renders in the bubble and in tool steps.
  Publish the picture to an image host first.

### Sessions, pairing, delegates

- `session_search` finds this agent's messages. `sessions_history` can read
  around a hit (`around_message_id`).
- `gateway.master_pair_code` mints a device token without using up the one-time
  pairing code. It is a secret, and it does nothing while pairing is off.
- Nested background delegates stay visible to their caller.

## Breaking changes inherited from upstream v0.8.6

Review the upstream list before upgrading. The ones most likely to affect an
existing ZeroLite install:

- Pairing codes default to 32 characters and reading or minting them needs the
  gateway admin token. Set `[gateway.pairing_code] length = 6, charset = "numeric"`
  for the old shape.
- Remote WSS needs `auth_token`; `[security.nevis]` is retired in favour of
  `[oidc.<alias>]`.
- `[browser] enabled = true` no longer implies the `browser` automation tool; set
  `browser.automation_enabled = true`.
- `file_download` refuses private-network hosts unless they are listed in
  `[file_download] allowed_private_hosts`.
- Full autonomy no longer overrides `always_ask`.
- The shell follows the platform default; set `runtime.shell = "sh"` or `"cmd"`
  to pin the previous choice.
